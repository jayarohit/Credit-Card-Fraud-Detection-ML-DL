**Credit Card Fraud Detection using Machine Learning & Deep Learning**  
*Python | Scikit-learn | TensorFlow/Keras | Pandas | NumPy | SMOTE*

- Compared Logistic Regression, Decision Tree, Random Forest, and a TensorFlow/Keras Artificial Neural Network with and without SMOTE using a stratified 64:16:20 train/validation/test split.
- Evaluated fraud-classification performance using Precision, Recall, F1-score, ROC-AUC, Average Precision, and confusion matrices; observed higher recall with SMOTE and the best F1-score (82.63%) from Random Forest without SMOTE at a 0.50 threshold.
